# 点歌机（钉钉 × 网易云）

在钉钉群里 @机器人 点歌，歌曲在**这台电脑**上播放。原生 Windows 程序，只有一个文件：**`点歌机.exe`**，复制到任何 Windows 10/11 电脑上双击就能用，不需要安装 Python、Node、.NET 或 ffmpeg。

- 选择输出设备（音箱 / 耳机 / 蓝牙），播放中切换会从当前位置接着放
- 播放列表：拖动排序、置顶、上移下移、删除、清空
- 手动搜索点歌、插队；导入网易云歌单；没人点歌时随机播放「空闲歌单」
- 网易云扫码登录，登录 VIP 账号后可以播放 VIP 歌曲（最高无损 FLAC）
- 关闭窗口后缩到右下角托盘继续播放

钉钉使用 **Stream 模式**：程序主动连接钉钉服务器，电脑不需要公网 IP，也不用做内网穿透。

## 一、创建钉钉机器人（只需做一次）

1. 打开 [钉钉开发者后台](https://open-dev.dingtalk.com/)，用组织管理员（或有开发者权限的账号）登录
2. **应用开发 → 钉钉应用 → 创建应用**，名字随便起，比如"点歌机"
3. 进入应用 → **添加应用能力 → 机器人** → 填写名称、简介、头像，**消息接收模式选「Stream 模式」**，保存
4. **凭证与基础信息**：复制 `Client ID` 和 `Client Secret`
5. **版本管理与发布 → 发布**（可见范围设置为需要用的人）
6. 钉钉群 → **群设置 → 机器人 → 添加机器人**，搜索并添加这个机器人（也可以直接私聊它）

## 二、开始使用

1. 双击 **点歌机.exe**
2. 左侧 **设置** → 填写 Client ID 和 Client Secret → **保存设置**，左下角显示"钉钉：已连接"就好了
3. **扫码登录**网易云（用网易云音乐 App 扫码）
4. 底部播放栏右侧选择**输出设备**（插了新设备后点旁边的刷新按钮）

关闭窗口不会停止播放。双击托盘图标（或再次双击 exe）打开窗口；右键托盘图标可以暂停、切歌、退出。

## 钉钉指令

在群里 @机器人 发送（私聊不用 @）：

| 发什么 | 效果 |
|---|---|
| `晴天` 或 `点歌 晴天` | 点搜索结果里的第一首 |
| `搜 晴天` → `选 3` | 先列出搜索结果，再点第 3 首 |
| `点歌` + 网易云分享链接 | 精确点歌（支持 music.163.com 和 163cn.tv 短链接） |
| `列表` / `当前` | 看播放列表 / 正在放的歌 |
| `切歌` | 跳过当前这首（所有人都能用） |
| `暂停` / `继续` | 暂停 / 继续 |
| `删除 2` | 删除列表第 2 首（只能删自己点的） |
| `置顶 2` / `清空` / `音量 60` | 管理员指令 |
| `帮助` | 显示指令说明 |

管理员在 **设置 → 点歌规则** 里填写（钉钉昵称，逗号分隔）。留空表示所有人都是管理员。

## 数据存在哪里

| 位置 | 内容 |
|---|---|
| `%APPDATA%\点歌机\settings.json` | 设置。**Client Secret 用 Windows DPAPI 加密保存**，文件里没有明文 |
| `%APPDATA%\点歌机\netease.dat` | 网易云登录信息，整个文件用 DPAPI 加密 |
| `%APPDATA%\点歌机\state.json` | 播放列表（重启后恢复） |
| `%LOCALAPPDATA%\点歌机\cache\` | 歌曲缓存（自动保留最近 40 首） |
| `%LOCALAPPDATA%\点歌机\logs\` | 运行日志 |

DPAPI 加密绑定当前 Windows 账号：别人拷走这些文件也解不开；换电脑或换 Windows 账号后需要重新填写 Secret、重新扫码登录。设置页里有按钮可以直接打开这两个文件夹。

## 常见问题

- **钉钉显示连接失败**：检查 Client ID / Secret，确认机器人是 Stream 模式并且应用已经发布
- **群里 @ 了没反应**：确认机器人已经加进这个群，程序左下角显示"钉钉：已连接"
- **提示只能试听 30 秒**：没有登录 VIP，或者这首歌是数字专辑、需要单独购买
- **提示无版权**：网易云上没有这个版本，发 `搜 歌名` 换一个版本点
- **其他问题**：设置 → 运行日志 → 打开，查看 `点歌机.log`

## 开发

源代码在 `desktop/`（C# / WPF / .NET 8）：

| 文件 | 作用 |
|---|---|
| `Core/NcmClient.cs` | 网易云接口（eapi 加密） |
| `Core/AudioPlayer.cs` | 播放（Media Foundation 解码 + WASAPI 输出） |
| `Core/Jukebox.cs` | 播放队列、空闲歌单、下载缓存 |
| `Core/DingTalkBot.cs` | 钉钉 Stream 连接和点歌指令 |
| `Core/AppSettings.cs` | 设置和加密存储 |
| `MainWindow.xaml` / `MainViewModel.cs` | 界面 |

改完代码后双击 **`build.bat`** 重新生成 `点歌机.exe`（需要 .NET 8 SDK）。
